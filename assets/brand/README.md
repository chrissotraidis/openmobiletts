# Open Mobile TTS Brand Assets

**Selected direction:** visual option 1, chosen by the project owner on
2026-08-11.

The mark uses two facing text planes with six negative-space waveform bars. It
is intentionally letter-free so the same symbol can serve Android, a future
iOS app, the local web interface, favicons, documentation, and social assets.

## Sources

- `open-mobile-tts-icon-master.png` — selected full-square raster master.
- `open-mobile-tts-icon-foreground.png` — transparent adaptive foreground.
- `open-mobile-tts-ios-master.png` — opaque 1024 × 1024 iOS-ready master.

The selected concept and transparent foreground were produced with the built-in
ImageGen workflow. Platform sizes are deterministic resizes of those reviewed
masters; they are not independently regenerated variants.

## Selected concept prompt

> Create one production-quality app icon direction for Open Mobile TTS that
> combines reading/text and spoken audio in a single memorable silhouette. Use
> two text planes whose central negative space becomes a clean voice waveform.
> Keep it recognizable at favicon size, letter-free, vector-friendly, and
> grounded in the app's dark charcoal and electric-blue visual system.

Do not edit one platform icon independently. Update the reviewed master first,
then regenerate the Android, web, documentation, and future iOS sizes together.
